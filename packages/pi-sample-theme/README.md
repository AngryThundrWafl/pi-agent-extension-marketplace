# @local/pi-sample-theme

Starter dark slate theme package for Pi demonstrating conventional `themes/` auto-discovery.

## Install

```bash
pi install ./packages/pi-sample-theme
```

## Usage

Preview the theme directly without installing:

```bash
pi -e ./packages/pi-sample-theme --use-theme sample-slate
```

Once installed, select `sample-slate` interactively in Pi with:

```text
/theme
```

## Included Themes

- `themes/sample-slate.json` (`sample-slate`, dark appearance)
